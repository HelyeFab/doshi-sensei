# Product Overview

**Doshi Sensei** is a comprehensive Japanese language learning Progressive Web App (PWA) built with Next.js. The application focuses on interactive Japanese language education with emphasis on verb conjugations, vocabulary acquisition, and immersive learning experiences.

## Core Features

- **Japanese Verb Conjugation Practice** - Interactive exercises for ichidan, godan, and irregular verbs
- **Vocabulary Search & Dictionary** - 22,569+ entries from JMdict Simplified with offline capability
- **Kanji Browser & Study Tools** - Comprehensive kanji learning with mood boards and visual organization
- **Interactive Games** - Gamified learning experiences including Pokemon-style battles and mini-games
- **Study Lists & Bookmarks** - Personal vocabulary and sentence collection management
- **News Reading** - Japanese news articles with integrated learning tools
- **AI Story Generation** - Custom Japanese stories with character consistency
- **Progressive Web App** - Installable on mobile devices with offline support

## Target Audience

Japanese language learners from beginner to advanced levels, with particular focus on JLPT preparation and practical language application.

## Key Differentiators

- Offline-first architecture with comprehensive caching
- Gamification through Pokemon-style elements
- AI-powered story generation for contextual learning
- Multi-modal learning (visual, audio, interactive)
- Freemium model with premium subscription features

## Business Model

- **Freemium Structure** - Core features free, premium features require subscription
- **Stripe Integration** - Monthly/yearly subscription payments
- **Firebase Backend** - User authentication, data sync, and subscription management
- **Admin Dashboard** - User management and analytics for admin users
