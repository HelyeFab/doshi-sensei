## Additional Considerations

### Service Worker Cache
The service worker (sw.js) references 2,136 icon files from various collections. However, these appear to be pre-cached for offline support and are not all actively used in the application.

### Directory Structure Required
Based on the paths, you'll need to create the following directory structure under `/public/flat-icons/`:
- 188915-pokemon-go/png/
- 8376275-wild-animals-flat-1-of-1/svg/
- 4193242-animals/svg/
- 17517790-summer-watermelon/svg/
- 4341021-education/png/
- 4341021-education/svg/

### Restoration Priority
1. **Critical Icons** (directly visible in UI):
   - /flat-icons/8376275-wild-animals-flat-1-of-1/svg/007-giraffe.svg (Companion trigger)
   - /flat-icons/4341021-education/png/006-whistle.png (Help icon)
   - Pokemon Go PNG icons (Pokedex feature)

2. **Virtual Companion Icons**: All the animal and emotion SVGs listed above are used for the virtual companion feature

3. **Optional**: The service worker cached icons could be restored later for full offline support, but the app will function without them.
