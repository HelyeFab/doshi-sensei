## Insights from news-crawler Repository

After analyzing [airRnot1106/news-crawler](https://github.com/airRnot1106/news-crawler), we learned:

### Key Findings
1. **NHK News Selectors** (for regular NHK, not Easy):
   - `section.module--detail-content` - Main content section
   - `h1` - Article title
   - `time` - Article date with `datetime` attribute
   - `figure img` - Thumbnail image
   - `.content--detail-main` - Main article body
   - `p,img` - Content paragraphs and images

2. **They Also Scrape**:
   - Yahoo! News Japan (`https://news.yahoo.co.jp/`)
   - Both sources use Puppeteer for JavaScript rendering

### New Scraper Created
- `scrape-nhk-improved.js` - Implements NHK News scraping using selectors from news-crawler
  - Targets regular NHK News (N3 level) instead of NHK Easy
  - Uses Puppeteer with proper content extraction
  - Structured data extraction (separates paragraphs, images, metadata)

## Troubleshooting

### If scrapers return no content:
1. Check if the target site has changed structure
2. Verify CSS selectors are still valid
3. Try the Puppeteer version for JavaScript-heavy sites
4. Check browser console for any API endpoints that could be used directly

### Common Issues:
- **Timeout errors** - Increase timeout in Promise.race() calls
- **Memory errors** - Use standard version instead of Puppeteer
- **No content found** - Update selectors or check if site requires auth
